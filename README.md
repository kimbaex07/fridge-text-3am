# The 3AM Fridge Text

The one line a smart fridge texts its owner at 3am.

> It's 3am. Fourth night in a row. I keep the light on for you and you repay me by eating standing up in the dark.

**Character count: 112** (gate: 1–140 characters, single line).

## Why it lands

The fridge isn't just cold storage here — it's a tired, loyal roommate keeping score ("Fourth night in a row") and holding a small grudge, which is exactly the machine-with-a-small-voice the judge wants. The punchline is a specific, visual image everyone recognises — eating standing up in the dark at 3am — instead of the tired milk/ice/door-open angles. And it reads complete on a lock screen: a guilt trip, a joke, and a confession all in one line, with no follow-up needed.

## How to run

```sh
MAKEFUN_OUTPUT_DIR=./out python3 main.py
```

Writes the line to `$MAKEFUN_OUTPUT_DIR/entry.txt` (pure Python stdlib, no third-party imports).
